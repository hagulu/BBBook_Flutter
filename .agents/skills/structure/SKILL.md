# 파일 구조

## 규칙
- 새 파일 생성 시 아래 구조를 따른다.
- 필요한 파일과 폴더만 생성하며, 사용하지 않는 계층을 미리 만들지 않는다.

- `lib/`
  - `main.dart` : 앱 진입점
  - `app/` : 앱 설정, 라우팅, 테마
  - `core/` : 네트워크, 공통 설정, 유틸
  - `features/` : 기능별 화면, 위젯, 모델, 서비스
  - `shared/widgets/` : 여러 기능에서 공통으로 사용하는 UI 위젯

- `features/{기능명}/`
  - 해당 기능에 필요한 화면, 위젯, 모델, 서비스 파일을 함께 둔다.
  - 기능 내부에서만 사용하는 위젯은 해당 기능 폴더에 둔다.
  - 두 개 이상의 기능에서 반복 사용되는 UI만 `shared/widgets/`로 분리한다.

- `test/`
  - `lib/` 구조에 대응하여 구성한다.
