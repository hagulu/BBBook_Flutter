## 규칙
- 리뷰는 요청된 경우에만 수행한다.
- 불필요한 리팩토링 제안은 하지 않는다.
- 실제 문제나 개선 가치가 있는 부분만 지적한다.
- 사소한 스타일, 취향 차이는 지적하지 않는다.
- Flutter/Dart 구조와 위젯 생명주기에 맞는 문제를 우선 확인한다.

## 체크리스트
- 구조: `main.dart` / app / feature / screen / widget 역할 분리
- 위젯: `StatelessWidget` / `StatefulWidget` 선택, `build()` 부작용, 생명주기 처리 적절성
- 데이터: API 호출 위치, 중복 요청, 로딩·오류·캐싱 처리 적절성
- 상태: 지역·공유 상태 사용 범위, controller/listener 해제, `mounted` 확인
- 타입: 생성자 인자, API response, model, form data 타입과 null safety 명확성
- 라우팅: 화면 책임, 이동 흐름, 인자 전달, 뒤로 가기 처리 적절성
- 보안: 앱 내 비밀값 포함, 인증/인가, 토큰 저장, 민감 정보 노출 여부
- 성능: 불필요한 rebuild, `const` 누락, 긴 목록 렌더링, 이미지·리소스 관리
- 접근성: `Semantics`, 터치 영역, 텍스트 배율, 키보드·스크린 리더 기본 문제
