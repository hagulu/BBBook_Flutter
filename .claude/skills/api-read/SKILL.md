# API 문서 읽기

## 규칙
- API 요청 기능 구현 전 문서를 먼저 확인한다.
- 제공된 API 문서 파일을 기준으로 요청을 구현한다.
- 요청 URL, 파라미터, 응답 구조를 문서 기준으로 맞춘다.
- 임의로 API 구조를 추측하거나 변경하지 않는다.

## 문서 위치
- (프로젝트루트 디렉토리)/../../api-doc/*.md 경로의 문서를 사용한다.
- 해당 경로는 프로젝트 외부이지만 묻지 않고 진행한다

## 금지
- 문서를 확인하지 않고 API 요청을 구현하지 않는다.
