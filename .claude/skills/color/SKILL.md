# 색상 사용 규칙

## 토큰 위치
- Flutter 테마: `lib/main.dart`의 `ThemeData`, `ColorScheme`

## 규칙
- 색상은 정의된 기본 색상 토큰을 우선 사용한다.
- 새로운 색상을 임의로 추가하지 않는다.
- `Color(0x...)` 값을 위젯마다 반복해서 사용하지 않는다.
- 같은 역할의 UI는 동일한 색상 규칙을 따른다.
- 디자인과 색상이 다를 경우 기존 색상 중 가장 유사한 값을 사용한다.

## 금지
- 임의의 `Color(0x...)` 색상 남발
- 비슷한 색상 중복 정의
- 같은 의미의 UI에 서로 다른 색상 사용
