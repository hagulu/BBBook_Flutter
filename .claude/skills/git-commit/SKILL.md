# Git Commit

## 규칙

- 변경사항을 확인한다.
- 변경 내용을 바탕으로 커밋 메시지를 한글로 정리해서 작성한다.
- 모든 변경사항을 스테이지에 올린 후 커밋한다.

## 에러

- 발생한 에러 내용만 간단히 보고한다.
- 에러를 해결하기 위한 추가 명령어나 수정 작업은 하지 않는다.

## 금지

- `git push` 및 원격 저장소에 영향을 주는 명령어
- `git reset`, `git rebase`, `git checkout .` 등 파괴적·수정 작업
- 변경 내용 수정
