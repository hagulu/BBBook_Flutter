## 개선 제안
- 2열 진입 타일 무한 높이 → `Row`의 `CrossAxisAlignment.stretch`를 제거한다. 두 타일의 높이를 반드시 맞춰야 한다면 유한 높이 제약을 명시하거나 작은 범위에서 `IntrinsicHeight`로 감싼다.
- 등록 성공 오판 → POST 성공과 목록 재조회 결과를 별도 상태로 반환하고, 재조회만 실패한 경우에는 `등록되었지만 목록을 새로고침하지 못했습니다.`로 안내한 뒤 별도 재시도를 제공한다. 최소한 `false`를 등록 실패로 표현하지 않는다.
- 공감 연속 요청 경합 → 항목 ID별 요청 진행 상태로 완료 전 버튼을 비활성화하거나, 최신 목표 상태를 보관하는 직렬화 큐로 POST/DELETE를 순서대로 처리한다. 공개 독후감의 보호 방식을 공통 정책으로 재사용할 수 있다.
- 독자평 시트 가로 overflow → 별점과 스포일러 토글을 세로로 배치하거나 `Wrap`으로 줄바꿈 가능하게 구성한다. 별점 버튼의 44px 터치 영역은 유지한다.
- 갱신되지 않는 상대 시각 → 절대 시각을 유지하거나, 상대 시각이 필요하면 분 단위 등 필요한 최소 주기로 다시 빌드하는 공용 위젯을 사용한다.
- 빈 답변의 활성 등록 버튼 → `TextEditingController`를 구독해 trim한 본문이 비어 있으면 `RecordDialogButton.onPressed`를 null로 전달한다.
- 작은 인라인 공감 터치 영역 → 아이콘의 시각 크기는 유지하되 `ConstrainedBox` 등으로 최소 44×44px 터치 영역을 보장한다.
