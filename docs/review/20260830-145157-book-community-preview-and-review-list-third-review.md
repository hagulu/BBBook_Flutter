## 개선 제안
- 독후감 배지와 실제 목록 불일치 → 가장 안전하게는 서버가 인증 사용자를 제외한 개수 또는 `myPublicReflectionCount`를 같은 응답 스냅샷으로 반환하게 해 공개 목록 기준과 맞춘다. 클라이언트에서 보정해야 한다면 검색 상세에도 `userBookId`를 전달하고, 서버에 반영된 공개 글만 빼며, 생성·수정·삭제·공개 변경의 서버 반영 완료 시 커뮤니티 개수 provider를 함께 무효화한다. 로컬 저장 모드의 글은 서버 개수에서 빼지 않는다.
- 추가 로딩과 실패한 새로고침 경합 → 첫 페이지 재조회가 기존 추가 로딩을 무효화할 때 `isLoadingMore`를 명시적으로 해제하거나, 재조회 실패 시 기존 추가 로딩 세대를 계속 유효하게 둔다. 성공·실패·세대 불일치 모든 경로에서 로딩 플래그가 종료되는지 검증한다.
- 독자평 공감 연속 요청 → 리뷰 ID별 요청 진행 상태로 완료 전 버튼을 비활성화하거나, 최신 목표 상태를 보관한 직렬화 큐로 POST/DELETE를 순서대로 처리한다.
- 커뮤니티 요청 결합 → `BookCommunityPreview`가 응답의 독후감·토론 개수를 파싱하고 미리보기와 개수 상태를 독립적으로 유지한다. 독자평 전체 개수가 필요한 생각나눔 탭에서만 `community-counts`를 추가 요청해 부분 성공 데이터는 계속 표시한다.
