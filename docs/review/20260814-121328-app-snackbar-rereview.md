# 리뷰 결과

## 요약
- 공통 `AppSnackBar`와 호출부는 정적 분석을 통과했지만, 이전 리뷰에서 확인한 오류 색상 대비와 메시지 큐 초기화 문제가 수정되지 않은 상태다.

## 문제점
- [접근성] `lib/shared/widgets/app_snackbar.dart:91`에서 오류 배경에 `AppColors.error`를 88% 불투명도로 사용하고 `lib/shared/widgets/app_snackbar.dart:103`에서 14px 흰색 텍스트를 표시한다. 밝은 배경 위의 실제 합성색은 약 `#E45353`으로 흰색과의 대비가 약 3.71:1이며, 일반 크기 텍스트의 권장 대비 4.5:1에 미달한다.
- [사용자 안내] `lib/shared/widgets/app_snackbar.dart:22`에서 모든 스낵바를 표시하기 전에 `clearSnackBars()`를 호출한다. 기존 호출부 중 바코드 연속 스캔만 명시적으로 큐를 비웠지만, 현재는 리뷰 좋아요·수정·신고 등의 모든 안내가 같은 동작을 사용한다. 비동기 결과가 연이어 도착하면 먼저 표시된 오류와 대기 메시지가 제거되어 사용자가 중요한 실패 내용을 확인하지 못할 수 있다.

## 개선 제안
- 오류 텍스트의 낮은 대비 → 밝은 화면 위에 합성된 최종 색상을 기준으로 흰색과 4.5:1 이상의 대비가 확보되도록 오류 배경을 더 어둡게 조정하거나, 배경과 함께 대비가 보장되는 전경색 토큰을 사용한다.
- 모든 호출에서 메시지 큐 초기화 → 기본 동작은 기존 큐를 유지하고, 바코드 연속 스캔처럼 최신 메시지만 필요한 호출부에만 `replaceCurrent` 옵션을 전달해 선택적으로 `clearSnackBars()`를 호출한다.
