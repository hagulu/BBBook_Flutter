# 리뷰 결과

## 요약
공감 중복 터치와 등록 후 재조회 실패는 구분하지만, 작성·수정 요청 자체가 실패하면 입력 내용을 잃습니다. P2 1건입니다.

## 확인 범위
책 상세의 리뷰 미리보기, 리뷰 전체 목록, 작성·수정·삭제, 별점 삭제, 스포일러, 공감, 신고, 다음 페이지와 새로고침을 확인했습니다.

## 문제점

### [REV-01][P2] 리뷰 입력 시트를 먼저 닫아 네트워크 실패 시 작성 내용을 복구하지 못함

- 일반 조건: 사용자가 내용을 입력하고 등록/저장을 눌렀는데 연결 전환·오프라인·서버 오류로 POST/PATCH가 실패합니다.

## 개선 제안

서버 요청 결과가 확인될 때까지 시트와 입력을 유지하거나, 실패 시 방금 입력한 draft로 시트를 다시 열 수 있게 합니다. 토론 답변 시트가 이미 사용하는 비동기 제출·실패 시 입력 유지 방식을 재사용할 수 있습니다.

## 확인된 보호 장치

- 리뷰별 공감 요청 ID 집합으로 겹친 터치를 막고 오류를 안내합니다.
- 등록 성공과 목록 재조회 실패를 분리해, 이미 저장된 리뷰를 실패라고 안내하지 않습니다.
- loadMore의 응답 세대 검사로 새로고침 이전 커서의 응답을 버립니다.
- 별점 삭제는 clear 필드로 구분하고 리뷰 내용은 150자 입력 한도를 적용합니다.
- 신고·작성 등 계정 필요 기능과 징계 제한 진입점을 구분합니다. 서버 인가 우회 여부는 백엔드 코드를 읽지 않았으므로 판단 범위에 포함하지 않았습니다.
