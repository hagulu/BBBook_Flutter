# 리뷰 결과

## 요약
연속 스캔 중 요청 가드는 있지만 생명주기, 모달 위 인식, 가이드 범위, 로컬 빠른 등록 정보에 문제가 있습니다. P2 4건입니다.

## 확인 범위
일반 스캔, 연속 빠른 등록, 상태 변경, 같은 바코드 반복, 비ISBN 안내, 권한 오류, 도움말 모달, 홈/잠금 후 복귀, 로컬 모드/계정 없이 사용을 확인했습니다.

### [DEV-02][P2] 화면 중앙 가이드 밖의 바코드도 빠른 등록 대상으로 인식함

- 근거: 같은 MobileScanner 생성부에 `scanWindow`가 없습니다. `_ScanFrame`은 장식용 테두리만 그립니다.
- 일반 조건/영향: 두 권을 함께 들거나 옆 책의 바코드가 화면에 보이면 중앙 사각형 밖의 ISBN을 선택할 수 있습니다. 빠른 등록에서는 상세 확인 없이 그 책이 추가됩니다.

### [DEV-03][P2] 로컬 모드의 빠른 등록은 책 제목이 ‘ISBN 번호’인 상태로 계속 남음

## 개선 제안

- DEV-01: 권한·초기화 상태를 확인하면서 앱 lifecycle에 맞춰 scanner stop/start를 처리합니다. 공용 사진 카메라의 구현을 통째로 가져오기보다 플러그인의 controller 계약에 맞는 최소 observer를 둡니다.
- DEV-02: 실제 레이아웃 기준 가이드 Rect를 scanWindow에 전달합니다.
- DEV-03: 로컬 모드 빠른 등록도 기존 공개 책 상세 조회로 메타데이터를 확보한 뒤 저장합니다. 조회 실패 시 재시도 또는 ISBN만 저장하는 선택을 명확히 해야 하며, 서버 동기화를 몰래 켜서는 안 됩니다.
- DEV-04: 스캐너가 현재 화면일 때만 결과를 처리하고, 도움말 진입·종료에서 인식 일시 중단/재개를 맞춥니다.

## 확인된 보호 장치

등록 중 `_processing`, 같은 ISBN의 `_lastProcessedIsbn`, 이미 등록된 책의 409 구분이 있습니다. 요청 당시 독서 상태를 캡처하므로 중간에 상태 pill을 바꿔도 완료 문구가 다른 상태를 표시하지 않습니다. 978/979 13자리 형식을 확인하고 비ISBN 경고 타이머와 controller를 해제합니다.
