# 리뷰 결과

## 요약
책장 필터·로컬 조회·검색 응답 순서 제어는 갖춰져 있습니다. 직접 등록의 저장 중 화면 종료 처리에 P2 1건이 있습니다.

## 확인 범위
읽을 책/읽는 중/완독/중단 탭, 기본 탭 선택, 검색·태그·카테고리 필터, 메모/독후감 검색, 목록 보기 방식, 월 이동, 검색 결과 페이지 추가, 책 상세 담기, 직접 등록, 완독 옵션을 확인했습니다.

## 문제점

### [ADD-01][P2] 직접 등록 저장 중 뒤로 가기로 폼을 닫을 수 있어 생성 결과가 불명확해짐

- 근거: [custom_book_dialog.dart:128](/Users/hagulu/develop/service/BBBook/project/app/bbbook/lib/features/book_search/screens/widgets/custom_book_dialog.dart:128)의 `_save()`는 실행 중 플래그나 PopScope 없이 AppLoading Overlay만 사용합니다. Overlay는 시스템 뒤로 가기를 막지 않습니다. 실제 생성은 표지 사본 저장·복사를 거친 뒤 로컬 INSERT를 수행합니다.
- 일반 조건: 표지를 포함한 책을 저장하는 중 시스템 뒤로 가기로 시트를 닫습니다. 시작된 Repository 작업은 계속 실행될 수 있습니다.
- 영향: 폼이 사라져도 책이 생성되며, 호출부는 취소(null)로 받아 정상 완료 이동을 하지 않습니다. 위젯이 폐기된 뒤에는 ref를 사용하는 목록 갱신 단계도 실패할 수 있습니다. 사용자는 저장되지 않았다고 생각해 같은 책을 다시 등록할 수 있고, 직접 등록은 새 UUID를 사용하므로 중복을 합치지 않습니다.

## 개선 제안

저장 첫 진입에서 실행 중 플래그를 세우고, 저장 중에 한해 시트 닫기와 중복 실행을 막습니다. 필수 목록 갱신은 위젯 생존 여부와 분리합니다. 전체 앱에서 뒤로 가기를 금지하거나 직접 등록의 같은 제목 책을 자동 병합할 필요는 없습니다.

## 확인된 보호 장치

- 검색은 요청 세대로 이전 검색·페이지 응답을 버리고, 다음 페이지는 디바운스와 진행 상태를 확인합니다.
- 완독 로컬 검색은 소유자 조건을 사용하고 메모 강조 마크업을 제거해 검색합니다. 필터 변경 중에는 이전 필터 결과를 잘못 재사용하지 않도록 처리합니다.
- 탭 컨트롤러 길이 변경·월별 스크롤 오프셋·텍스트 배율에 대한 기존 보정이 있습니다. 실제 작은 화면 렌더링은 실행하지 않았습니다.
- 네트워크 재시도 버튼이 15초 대기를 풀지 못하는 문제는 [NET-01](../08-common/20261028-124818-network-navigation-security.md)에 있습니다.
- 바코드 빠른 등록은 [바코드 리뷰](../05-device/20261028-124818-barcode-scan.md)에 별도로 정리했습니다.
