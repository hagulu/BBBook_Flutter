# 리뷰 결과

## 요약

- 현재 변경된 독서 리포트 태그 통계 4개 파일에서 접근성 문제 1건을 확인했다. `flutter analyze`는 통과했다.

## 문제점

- [P2][스크린 리더에서 더보기·접기 버튼에 접근할 수 없음] `lib/features/profile/screens/widgets/reading_stats_tag_chart.dart:30-34` — 그래프 전체를 감싼 `Semantics(excludeSemantics: true)`가 하위 위젯의 의미 정보를 모두 제거한다. 태그가 6개 이상이면 `TextButton`으로 나머지 태그를 펼치거나 접을 수 있지만, 스크린 리더 사용자는 이 버튼을 탐색하거나 활성화할 수 없다. 대체 레이블은 접힌 상태에서도 전체 태그를 한 번에 읽어 상태와 조작 방법을 알려주지 않는다.

## 개선 제안

- 그래프 전체의 하위 의미 정보 제거 → 각 막대 행의 태그명·권수를 개별 `Semantics`로 제공하고, `TextButton`의 의미 정보는 유지한다. 접힌 상태에는 화면에 보이는 5개만 읽히게 하며, 버튼에 펼치기·접기 상태를 알 수 있는 레이블을 준다.

검증: `flutter analyze` 통과. 프로젝트 지침에 따라 앱과 테스트는 실행하지 않았다.
