# 리뷰 결과

## 요약
- 이전 리뷰의 독후감 편집기 즉시 예외와 공통 위젯의 불필요한 API·클립 문제는 해소됐지만, 긴 독후감 작성 중 핵심 저장 액션이 화면에서 사라지는 회귀 1건이 남아 있다.

## 문제점
- [중대] `lib/features/book_reflection/screens/book_reflection_editor_screen.dart:617` — 저장 버튼과 뒤로 가기 버튼을 `pinned: false`인 `SliverAppBar`에 넣어 두었다. 본문 입력 시 Quill이 같은 `_editorScrollController`로 커서를 화면에 맞추기 때문에 문서가 길어질수록 앱바가 자동으로 화면 밖으로 밀려난다. 이후 저장하려면 키보드를 내리고 문서 맨 위까지 다시 스크롤해야 하며, 일반 `AppBar`에 저장 버튼을 고정한 토론 작성 화면과도 동작이 어긋난다.

## 개선 제안
- 스크롤과 함께 사라지는 저장 액션 → 편집 화면은 일반 `AppBar`를 사용해 저장·뒤로 가기를 고정한다. 현재 슬리버 구조를 유지해야 한다면 최소한 `SliverAppBar.pinned`를 `true`로 바꿔 긴 문서와 키보드가 열린 상태에서도 저장 버튼에 즉시 접근할 수 있게 한다.
