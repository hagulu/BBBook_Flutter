# 리뷰 결과

## 요약
- 징계 상태 갱신, 토론 마감일 수정 제한, 마이 화면의 징계 안내를 다시 점검했다. 앞선 리뷰의 P1 1건과 P2 2건을 반영했고, 이 범위에서 추가로 확인된 미해결 문제는 없다.

## 문제점
- [반영][징계 해제 후 제한 UI가 복구되지 않음] 앱 복귀 시 징계 중인 사용자만 `/api/users/me`를 재조회하고, 징계 아이콘 선택 시에도 최신 상태를 확인하도록 연결했다. 주기적인 조회는 추가하지 않았다.
- [반영][징계 중 토론 마감일 수정 진입 가능] 토론 메뉴의 마감일 항목을 숨기고, 열린 시트에서 상태가 바뀌어도 저장 직전에 다시 제한 상태를 확인한다. 서버가 저장을 거부하면 시트 안에 오류 안내를 표시한다.
- [반영][큰 글씨에서 징계 안내가 잘림] 별도 상세 화면을 공통 `AppAlert` 팝업으로 바꿨다. 공통 팝업의 본문은 스크롤 가능하며 확인 버튼은 아래에 고정된다.

## 개선 제안
- 징계 표시에는 테마의 `error` 색을 적용했다. 서버가 안내하는 사유와 해제 예정 시각은 팝업에서 표시한다.
- 기존 테스트 외에 실제 기기 화면 크기별 시각 검증은 수행하지 않았다.
